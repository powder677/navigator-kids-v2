Parent Dashboard

What learned today

🎯 Skills Practiced

1. Prioritization (Mission Target)

Children with executive function challenges often feel paralyzed by multiple demands. Asking "What's my ONE thing?" reduces cognitive load and creates a clear starting point. This is the foundation of task initiation.

2. Task Initiation (Tiny First Step)

The biggest barrier is often starting. By identifying an absurdly small first step ("just look at the homework"), we bypass the overwhelm. Once started, momentum often carries forward. The phrase "What's the tiniest step?" is a powerful daily tool.

3. Activation Energy (3-2-1 Blastoff)

Countdowns create external structure for brains that struggle with internal "start" signals. The countdown provides a clear transition point from "not doing" to "doing." This works for transitions, starting tasks, or ending preferred activities.

4. Task Chunking (Checkpoint Stars)

Breaking large tasks into visible checkpoints makes progress concrete and provides dopamine hits along the way. Children with EF challenges often can't see the "middle" of tasks - checkpoints create a roadmap.

💬 Conversation Starters
  • "What's your ONE thing right now?"
  • "What's the tiniest first step for that?"
  • "Want to do a 3-2-1 Blastoff together?"
  • "Let's turn this into checkpoint stars - what's first?"
🏠 Practice Ideas
  • Morning routine: Use checkpoint stars for getting ready
  • Homework time: "What's your tiny first step?"
  • Transitions: "3-2-1 Blastoff to the car!"
  • Chores: Let them create their own checkpoint stars
  • Visual support: Print the recap card and reference it
⚠️ When They're Still Stuck

Executive function challenges are neurological, not willfulness. If these tools aren't working in the moment:

  • Body double: Sit with them while they work (your presence helps)
  • Make it tinier: "What if the first step was just picking up the pencil?"
  • Remove decisions: "Your ONE thing right now is homework"
  • Add movement: Sometimes a body break helps reset the brain
  • Check basics: Hunger, tiredness, and stress worsen EF
